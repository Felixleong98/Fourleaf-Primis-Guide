# 🍀 Primis

Primis is a large EliteMobs questing area. The story begins at Caeruleaum after a shipwreck and eventually reaches the Blood Temple.

## Quest types
- ◆ Main Quest — advances the main story.
- ○ Side Quest — optional quests with additional rewards.
- 🔍 Hidden Quest — deliberately obscure optional content.

## Regions
- ⚓ Caeruleaum
- 🌾 Farmstead & Mountain Pass
- ⛏️ Ogre Mines
- 🛡️ Gladius
- 🏛️ Pontis Mille
- 🌿 Pontis Mille Fields
- 🌲 Pontis Groves
- ⚔️ Blood Temple & Finale
