# Bandit Camp!

**Type:** Main  
**Region:** Caeruleaum  
**Given by:** Chief Piscis  
**Prerequisite:** Strangers in need...  
**Turn in:** Chief Piscis — `1240, 38, 309`

## 🎯 Objectives
- Kill 3 Acolyte Brutes
- Kill 2 Acolyte Rangers
- Kill 1 Ice Mage
- Retrieve the Lost Heirloom

## 🎁 Rewards
- 50 currency
- Caeruleaum's Hope (sword)
- Elite Scraps (various tiers)
