# The Crystal Elemental

**Type:** Main  
**Region:** Hidden Path  
**Given by:** Petrae  
**Prerequisite:** Blue flower path!  
**Turn in:** Eartep — `1409, 34, 593`

## 🎯 Objectives
- Kill 1 Quartz Elemental
- Speak to Eartep at the mountain passage exit
