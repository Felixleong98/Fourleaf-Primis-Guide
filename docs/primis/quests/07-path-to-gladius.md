# The path to Gladius

**Type:** Main  
**Region:** Farmstead  
**Given by:** Filius  
**Prerequisite:** The Farmstead  
**Turn in:** General Hasta — `830, 27, 662`

## 🎯 Objectives
- Kill 9 Undead Swashbucklers
- Kill 3 Undead Buccaneers
- Kill 1 Undead Captain
- Speak with the Lord of Gladius

## 🎁 Rewards
- 80 currency
- Enchanted Book (Protection)
